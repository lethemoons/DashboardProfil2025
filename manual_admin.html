Untuk Administrator Tingkat Provinsi

1. Pengenalan Role & Akses Admin

Dashboard Profil Kesehatan Provinsi Jawa Timur memiliki dua mode akses: Guest (untuk publik melihat data) dan Admin (untuk pengelola data memperbarui informasi database backend).

Halaman khusus Admin tidak dapat diakses tanpa login. Segala perubahan yang Anda lakukan sebagai Admin pada database akan secara langsung (real-time) memperbarui visualisasi yang dilihat oleh Guest.

2. Prosedur Login Admin

Untuk mengakses panel kontrol:

  1. Pilih menu Admin Dashboard pada sidebar sebelah kiri bawah.
  2. Anda akan diarahkan ke form login khusus.
  3. Masukkan Username dan Password (kredensial standar yang diberikan oleh pengelola server).
  4. Klik Login untuk masuk.
Gambar 1: Halaman Login Admin Dashboard

3. Antarmuka Admin Dashboard

Setelah login, Anda akan melihat halaman tabel data yang komprehensif. Halaman ini digunakan untuk melihat, mengekspor, serta memanajemen data mentah yang menjadi tulang punggung dashboard.

Gambar 2: Tampilan Utama Admin Dashboard (Tabel & Filter)

Fitur pada halaman ini meliputi:

  • Kolom Pencarian: Cari nama kabupaten/kota atau nama matriks.
  • Tabel Pagination: Memuat 50 baris data per halaman dengan navigasi Previous/Next.
  • Filter Tahun Global: Tabel ini disinkronisasikan dengan dropdown tahun di pojok kanan atas layar (Top Bar).

4. Data Preprocessing (Persiapan Data)

Sebelum Anda dapat mengunggah data ke dalam Dashboard, data mentah (raw data) yang dimiliki oleh Dinas Kesehatan harus melalui proses Data Preprocessing. Proses ini mengubah struktur data dari format cetak Excel Kemenkes menjadi struktur long-format CSV yang dapat dipahami oleh sistem Dashboard.

Mengapa Preprocessing Diperlukan?

Data mentah seperti file 14072026_Lampiran Profil Kesehatan 2025 FIX.xlsx berisi puluhan sheet dengan format tabel yang kompleks (termasuk kolom berlapis, merged cells, dan baris kosong). Dashboard membutuhkan data yang sudah terstruktur rapi dan seragam (standar CSV).

Langkah-langkah Data Preprocessing:

  1. Siapkan File Excel Mentah: Pastikan Anda memiliki file Excel Lampiran Profil Kesehatan yang sudah terisi lengkap (misal: 14072026_Lampiran Profil Kesehatan 2025 FIX.xlsx).
  2. Letakkan File di Folder Proyek: Pindahkan file Excel tersebut ke dalam folder utama proyek (root directory) tempat kode dashboard berada.
  3. Buka Terminal / Command Prompt: Buka aplikasi terminal dan arahkan (cd) ke folder proyek dashboard Anda.
  4. Jalankan Script Preprocessing: Sistem telah menyediakan script Python khusus untuk mengekstrak data. Jalankan perintah berikut: 
    python parse_kabupaten.py
  5. Tunggu Proses Selesai: Script akan membaca seluruh 88 sheet pada Excel. Proses ini memakan waktu beberapa detik hingga satu menit.
  6. Hasil Output (kabupaten_all.csv): Setelah berhasil, script akan menghasilkan sebuah file bernama kabupaten_all.csv di dalam folder proyek. File CSV inilah yang sudah siap untuk diunggah ke dalam Dashboard.

5. Pengelolaan Data & Pembaruan (Overwrite = Update)

Pembaruan data pada sistem ini dirancang menggunakan sistem Unggah Ulang (Re-upload / Overwrite).

Memperbarui Data (Overwrite = Update) Untuk memperbarui data yang sudah tersimpan, Admin melakukan input kembali data pada periode, wilayah, dan indikator yang sama. Data baru akan menggantikan nilai data sebelumnya. Dashboard tidak menyediakan fitur pengeditan langsung pada setiap cell tabel.

Perhatian: Pastikan nilai yang dimasukkan sudah benar sebelum menyimpan, karena data baru akan menggantikan data sebelumnya pada kombinasi data yang sama.

Langkah Mengunggah / Memperbarui Data (Import CSV):

Gambar 3: Panel Tombol Aksi Admin (Unggah, Unduh, Hapus)
  1. Klik tombol Unggah Data di panel atas kanan.
  2. Sistem akan membuka baris form kecil berisikan input Tahun dan tombol unggah.
  3. Pastikan Anda mengetikkan tahun data yang ingin diunggah dengan benar (misal: 2025). Jika tahun yang Anda tuju sudah memiliki data, maka proses ini akan menimpa data lama (overwrite).
  4. Klik tombol Pilih & Unggah File dan pilih file kabupaten_all.csv hasil preprocessing Anda.
  5. Tunggu hingga sistem selesai memproses file.
  6. Jika berhasil, akan muncul notifikasi "Import successful" dan tabel data otomatis dimuat ulang.

6. Mengekspor & Menghapus Data

A. Ekspor Data (Unduh)

Jika Anda memerlukan backup data atau butuh templat tabel saat ini, klik tombol Unduh Data (Tahun). Sistem akan men-generate file berformat CSV dari seluruh data di tahun yang sedang aktif terpilih di Top Bar.

B. Menghapus Baris Individual

Pada tabel data, terdapat tombol merah Delete di paling kanan setiap baris. Gunakan ini jika terdapat entri ganda atau kesalahan spesifik pada satu record (satu nilai indikator untuk satu daerah).

C. Menghapus Seluruh Data Tahun Tersebut

Jika Anda ingin mereset seluruh indikator di tahun tersebut, klik tombol merah bertuliskan Hapus Data (Tahun) di pojok kanan atas. Fitur ini akan menghapus ribuan record sekaligus dan tidak dapat dikembalikan, sehingga sistem akan meminta konfirmasi ganda.

7. Log Out / Keluar Sesi

Jika telah selesai mengelola data, pastikan untuk menekan tombol Logout (kiri atas) agar sistem kembali ke mode publik (Guest) dan mengunci halaman manajemen. Ini penting untuk mencegah perubahan data yang tidak disengaja.
